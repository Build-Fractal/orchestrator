If the P0 hotfix ships and M040 stays unscheduled, then a Quick-profile project with **fixed parsers but no default capture path still produces a 0-MEM inject** — the exact field-note failure, now with green AC-2/AC-3 masking it. AC-1 (round-trip) and AC-6 (Quick-milestone-non-empty) would pass only on hand-promoted projects.
