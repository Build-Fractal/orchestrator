## Prerequisites

- P07 is complete; `scripts/migrate/migrate.sh` accepts `--source gsd2 --path <dir> --output <dir> --force`.
- `sqlite3` CLI is available on macOS (ships with the OS).
- The GSD2 adapter's SQL schema expectations are documented in `scripts/migrate/lib/sqlite-reader.sh` and produce output keyed by the table/column names below.

## Description

Create a deterministic, minimal GSD2-shaped fixture at `tests/fixtures/m003-p08-gsd-minimal/.gsd/` that causes every P01–P06 transform to emit non-zero output when migrated. This fixture is the primary end-to-end target for the P08 integration test (T03) and replaces reliance on the developer-specific lakeledger submodule as the CI-reachable validation surface.

The fixture must be reproducible: instead of committing an opaque binary `gsd.db`, commit a shell script (`build-fixture.sh`) and SQL seed (`seed.sql`) that generate `gsd.db` deterministically, plus the final `gsd.db` for convenience. This ensures the fixture can be regenerated by future contributors without reverse-engineering the binary.

## Steps

1. Create directory `tests/fixtures/m003-p08-gsd-minimal/` and subdirectory `tests/fixtures/m003-p08-gsd-minimal/.gsd/`.

2. Write `tests/fixtures/m003-p08-gsd-minimal/.gsd/seed.sql` with CREATE TABLE + INSERT statements covering every table the adapter reads:
   - `memories` (id TEXT PRIMARY KEY, seq INTEGER, category TEXT, content TEXT, source_unit_id TEXT, confidence REAL, hit_count INTEGER, created_at TEXT, updated_at TEXT, superseded_by TEXT)
     - Insert at least 3 rows across ≥2 categories (`pattern`, `gotcha`). Include one `relates_to` linkage by making entries reference each other via content hints (graph edges are built post-migration by `rebuild-index.sh`; for traversal to return ≥1, ensure the entries land in categories that `detect-overlap.sh` (P07/T03) will enrich — at minimum put two entries in the same category with similar content so co-occurrence triggers a relation).
   - `decisions` (id TEXT PRIMARY KEY, seq INTEGER, decision TEXT, scope TEXT, when_context TEXT, choice TEXT, rationale TEXT, revisable TEXT, made_by TEXT, superseded_by TEXT) — at least 2 rows.
   - `requirements` (id TEXT PRIMARY KEY, class TEXT, status TEXT, description TEXT, validation TEXT, source TEXT, supporting_slices TEXT, primary_owner TEXT, superseded_by TEXT) — at least 2 rows, at least one with `status='active'`.
   - `milestones` (id TEXT PRIMARY KEY, title TEXT, status TEXT, vision TEXT, created_at TEXT, completed_at TEXT) — at least 2 rows, with one `status='active'` and one `status='completed'`.
   - `slices` (id TEXT PRIMARY KEY, milestone_id TEXT, title TEXT, status TEXT, goal TEXT, sequence INTEGER) — at least 2 rows across both milestones.
   - `tasks` (id TEXT PRIMARY KEY, slice_id TEXT, milestone_id TEXT, title TEXT, status TEXT, description TEXT) — at least 2 rows.
   - `verification_evidence` (id INTEGER PRIMARY KEY, created_at TEXT, verdict TEXT, task_id TEXT, milestone_id TEXT, slice_id TEXT, command TEXT, exit_code INTEGER, duration_ms INTEGER) — at least 3 rows so telemetry aggregation produces non-zero output.

3. Write `tests/fixtures/m003-p08-gsd-minimal/build-fixture.sh`:
   ```bash
   #!/usr/bin/env bash
   set -euo pipefail
   DIR="$(cd "$(dirname "$0")" && pwd)"
   DB="$DIR/.gsd/gsd.db"
   rm -f "$DB"
   sqlite3 "$DB" < "$DIR/.gsd/seed.sql"
   echo "Built $DB"
   ```
   Make it executable (`chmod +x`).

4. Run `bash tests/fixtures/m003-p08-gsd-minimal/build-fixture.sh` to generate `tests/fixtures/m003-p08-gsd-minimal/.gsd/gsd.db`. Commit the resulting binary alongside the seed for fast CI startup.

5. Write `tests/fixtures/m003-p08-gsd-minimal/.gsd/memories-snapshot.json` — a JSON mirror of the `memories` table rows, so the JSON fallback path (when `gsd.db` is absent or corrupt) still succeeds. Format:
   ```json
   {
     "memories": [
       { "id": "MEM001", "category": "pattern", "content": "...", "source_unit_id": "M001/S01", "confidence": 0.90, "hit_count": 5, "created_at": "2025-06-01T00:00:00Z", "superseded_by": null },
       ...
     ]
   }
   ```

6. Create `tests/fixtures/m003-p08-gsd-minimal/.gsd/milestones/M001/` directory and write a minimal `SUMMARY.md` inside — at least 10 lines, YAML frontmatter with `id: M001`, plus a markdown body describing what shipped. This exercises P04's filesystem milestone scan path.

7. Write `tests/fixtures/m003-p08-gsd-minimal/README.md` (min 20 lines) documenting:
   - What the fixture is for (P08 end-to-end migration test).
   - How to regenerate `gsd.db` (`bash build-fixture.sh`).
   - Table-by-table row counts.
   - Why it's minimal (not exhaustive) — just enough to exercise every pipeline branch.

8. Smoke-test locally:
   ```bash
   TMP="$(mktemp -d)"
   bash scripts/migrate/migrate.sh --source gsd2 --path tests/fixtures/m003-p08-gsd-minimal --output "$TMP" --force
   ls "$TMP"
   cat "$TMP/MIGRATION-REPORT.md" | head -40
   ```
   Confirm `MIGRATION-REPORT.md` exists and every `## Knowledge|Decisions|Requirements|Milestones|Telemetry` section has at least one non-zero count. If any section reports 0, augment the seed until non-zero.

## Must-Haves

- The fixture exists at `tests/fixtures/m003-p08-gsd-minimal/.gsd/` with `gsd.db`, `memories-snapshot.json`, and at least one `milestones/M*/` subdirectory.
- `bash scripts/migrate/migrate.sh --source gsd2 --path tests/fixtures/m003-p08-gsd-minimal --output <tmpdir> --force` succeeds (exit 0) and produces a `MIGRATION-REPORT.md` with non-zero counts in every content category.
- `tests/fixtures/m003-p08-gsd-minimal/README.md` documents fixture regeneration.

## Constraints

- Bash 3.2 compatibility for `build-fixture.sh` (no associative arrays).
- Fixture must be deterministic: seeded `sqlite3` build must produce byte-identical `gsd.db` across runs on the same machine (use fixed timestamps in INSERT values; do not rely on `datetime('now')`).
- Do not include any real personal data from the developer's project — the fixture content is synthetic.
- Total fixture size: keep under 50 KB (target ~10 KB).
