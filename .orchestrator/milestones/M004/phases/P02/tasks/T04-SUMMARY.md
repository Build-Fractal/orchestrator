Created scripts/lib/guards.sh (130 lines) — the safety rail library fulfilling FR-224, US6 AS1-6, the Principle II amendment (structured events), NFR-200 (Bash 3.2), and NFR-203 (double-sourcing guard). Provides four guards with uniform contract: guard_payload_sanity blocks missing/empty/<100-char payload files before dispatch; guard_budget blocks when cumulative cost or duration exceeds caps (0/empty caps act as disabled, opt-in per axis, with numeric input sanitization via case patterns so garbage becomes 0); guard_output_sanity blocks missing/empty/<100-char agent outputs after dispatch; guard_phase_complete blocks when no P*-SUMMARY.md or SUMMARY.md exists in a phase directory or when the summary has no '## ' section header. All four guards route failure through a single _guard_block internal helper that checks orch_is_forced — when ORCH_FORCE is set the guard emits GUARD_WARNING with forced=1 and returns 0 instead of GUARD_BLOCKED + return 1 — so the force-override semantics stay consistent and every override is auditable via the event log. Thresholds are env-overridable via ORCH_GUARD_MIN_PAYLOAD_CHARS / ORCH_GUARD_MIN_OUTPUT_CHARS (default 100).
