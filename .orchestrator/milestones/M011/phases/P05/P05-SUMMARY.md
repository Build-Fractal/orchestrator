P05 integrates ingested spec chunks into the `/orchestrator-evaluate` and `/orchestrator-roadmap` commands so milestone decomposition becomes spec-driven rather than prompt-driven. Three coordinated tasks, each pure-additive wiring with no behavioral regressions to prior commands.

T01 delivered `scripts/state/spec-metrics.sh` — a single-purpose state helper that walks `knowledge/spec/<cat>/*.md` (orch_root sibling first, then SCRIPT_DIR-derived project root), skips non-empty `superseded_by` tips, and emits seven key=value lines (`requirements`, `stories`, `acceptance_criteria`, `constraints`, `non_goals`, `total`, `metrics_source=chunks`). `commands/evaluate.md` was edited with three targeted insertions: a chunks-first branch in "Count structural elements" that falls back to raw-spec regex when no chunks exist, a `metrics_source` output field bullet, and a Reference Files entry for the new helper. Three verify scripts (counts, skips-superseded, evaluate-doc-references) confirm behavior + doc wiring.

T02 delivered `scripts/knowledge/spec-story-graph.sh` — emits `<SPEC-US-ID>|<comma-sep deps>` lines by delegating 1-hop connectivity to `traverse-graph.sh` and layering a directional filter that re-reads the source story's `relates_to:` frontmatter (traverse-graph is bidirectional; `depends_on` is not). Superseded tips and superseded neighbors are both dropped. Registered a `roadmap` stage in `scripts/engine/intensity-gate.sh` with Quick=`single-pass`, Standard=`basic-decomp,rationale`, Full=`basic-decomp,rationale,collaborative-loop`, matching the existing stage-case idiom (and added to the unknown-stage allowlist). `commands/roadmap.md` received five targeted insertions: Prerequisites step 6 (intensity-gate call), Spec Analysis step 1 rewrite with chunks-first + raw-spec fallback, a new Intensity-Aware Interaction subsection, a Phase Decomposition bullet for chunk→phase mapping, and five new Reference Files bullets — all insertions, zero deletions, so T03's preservation regression stays green. Five verify scripts passing.

No production code landed in T03 — it's pure verification.
