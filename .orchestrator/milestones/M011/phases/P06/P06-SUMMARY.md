P06 closed out M011 (Spec Management) by delivering the user-facing `orchestrator:ingest` command document and the end-to-end validation suite that proves the ingest → scope-filter → spec-metrics → evaluate/roadmap pipeline works on a real in-repo spec. Three tasks, all pure-additive; no changes to production ingest/scope-filter/evaluate/roadmap code, and zero regressions against P03 / P04 / P05 verify suites.

T01 delivered `commands/ingest.md` — a new user-facing command (~90 lines, MEM012-shaped) with frontmatter description, title, Prerequisites, Usage (`--spec-path`, `--slug`, `--milestone`), a six-step Workflow, a Re-ingest / Idempotency section that names the P03 output prefixes literally (`SKIPPED:`, `SUPERSEDED:`, `REMOVED:`) and the `--force` gate, Error Handling, and a Reference Files block pointing at `ingest-spec.sh`, `rebuild-index.sh`, `spec-metrics.sh`, `scope-filter.sh`, and `knowledge/spec/`. Four doc-shape verify scripts were also added (`m011-p06-ingest-doc-structure.sh`, `-conventions.sh`, `-reingest-contract.sh`, `-evaluate-doc-mentions-ingest.sh`). `commands/evaluate.md` already referenced `orchestrator:ingest` from P05 T01 work (line 42 Chunks-first path; line 196 Reference Files), so no edit to evaluate.md was required — the plan explicitly anticipated this case. Key portability fix: BSD grep on macOS treats strings beginning with `-` as options, so all doc-shape verify scripts use the `grep -Fq -- "$tok"` end-of-options idiom.

T02 delivered the end-to-end gate scripts. `scripts/verify/m011-p06-e2e-pipeline.sh` stands up a sandbox `PROJECT_ROOT=$(mktemp -d)` with EXIT-trap cleanup, copies a multi-story fixture spec into `specs/<slug>/spec.md`, invokes `ingest-spec.sh --spec-path ... --slug ... --scope-tags "[project]"`, asserts non-zero `spec_chunks_present` from `spec-metrics.sh`, invokes `scope-filter.sh --category spec/story --graph` with the required positional placeholders, and asserts at least one `SPEC-US-` story ID is returned. `scripts/verify/m011-p06-e2e-pipeline-timing.sh` wraps the same sequence with `date +%s` bookends and asserts `elapsed_seconds < 60`. Two deviations were captured as decisions: ingest runs with `--scope-tags "[project]"` so chunks surface under the caller's scope context, and scope-filter.sh in `--graph` mode still requires `FILE_PATH` and `SCOPE_CONTEXT` positional args (placeholder `KNOWLEDGE-INDEX.md "M011/P06"`) — both workarounds avoid modifying the P04 scope-filter.sh, which was out of scope.

T03 delivered the dogfood evidence and the closing regression guards. A live ingest of `specs/016-autonomous-hardening/spec.md` produced the evidence set under `.orchestrator/milestones/M011/phases/P06/evidence/`: `ingest-transcript.txt` (20 CREATED lines), `spec-metrics.txt` (`spec_chunks_present=true`), `story-ids.txt` (3 `SPEC-US-` entries from the scope-filter --graph pass), and `timing.txt` (`elapsed_seconds=7`, well under the 60s threshold). Three final verify scripts round out the gate suite: `m011-p06-evidence-present.sh` is a file-exists + token-contains gate for each evidence artifact; `m011-p06-bash32-compat.sh` scans the eight other P06 verify scripts for `declare -A`, `mapfile`, `readarray`, and process substitution; `m011-p06-commands-preserve-references.sh` extends the P05 preservation guard to P06, verifying every prior Reference File bullet in `commands/evaluate.md` and `commands/roadmap.md` is still present.

Verification: 9/9 P06 verify scripts PASS (`run-suite.sh m011 P06` → `PASS: 9 / FAIL: 0`). P05 regression suite remains fully green (3/3), P04/P03 suites unchanged. External-mod check: PASS.

Notable patterns established: `grep -Fq -- <tok>` idiom for matching --flag tokens in doc-shape verify scripts under BSD grep; sandboxed `PROJECT_ROOT=mktemp -d` with EXIT-trap cleanup for full ingest pipeline tests; integer-only timing gate with `date +%s` bookends; evidence-present token gate (file-exists + token-contains) as the standard dogfood verification shape; regression guard for doc-preserved Reference File bullets extended phase-over-phase (P05 → P06). The dogfood evidence demonstrates the end-to-end "paste a spec, get a scope-filtered chunk tree in under 60 seconds" value proposition from the M011 feature spec.
