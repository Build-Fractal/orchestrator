P07 completed M011 by delivering Format-Agnostic Intake and a reusable Conversus fidelity gate. The "paste a random PRD" value proposition is now end-to-end: a developer can run `orchestrator:ingest` on a non-spec-kit-shaped markdown file, the command LLM-normalizes it to spec-kit shape, optionally runs a two-agent Conversus gate, and only on PASS (or explicit `--force`) does the deterministic chunker from P02/P03 run. Four tasks, pure-additive in P04/P05/P06 surfaces (zero behavioral regressions — P06 suite remains 9/9 green, P05 regression still 3/3 green).

T01 delivered the shape detection and normalization layer. `scripts/knowledge/detect-spec-shape.sh` is an agent-free probe classifier using seven heading-pattern probe families (emits `shape=speckit|foreign` with a `>=3` threshold). `scripts/knowledge/normalize-spec.sh` is a thin wrapper routing through `dispatch-interface.sh` (no hardcoded LLM calls, honoring the roadmap invariant); supports `--force`, `--output-dir`, a `NORMALIZER_STUB=1` escape hatch for deterministic testing, and atomic temp-then-rename with a `<!-- source_hash: <hex> -->` idempotency marker prepended to the output. `templates/spec-normalizer-prompt.md` provides the `{{source_markdown}}` / `{{slug}}` placeholder prompt; multi-line body substitution uses awk rather than sed to avoid metacharacter pitfalls.

T02 delivered the reusable Conversus adapter. `scripts/dispatch/adapters/tool/conversus.sh` exposes three subcommands (`check`, `gate`, `parse-verdict`) with a four-source binary resolver, `CONVERSUS_STUB` env-var escape, graceful-degradation SKIPPED path when the binary is absent, and a three-value exit contract (0=PASS or SKIPPED, 2=BLOCK, 1=error). `commands/conversus-gate.md` is the MEM012-shaped command doc (139 lines) designed so M013/M014 can reuse it with different presets. `templates/conversus-presets/normalize-fidelity.yml` is the two-agent (source-advocate vs target-advocate) deliberation preset. `templates/gate-result.md` is the canonical PASS/BLOCK result template with `{{placeholder}}` syntax. Deterministic `tests/fixtures/gate-result-{pass,block}.md` cover both verdict paths.

T03 integrated the two layers. `scripts/engine/intensity-gate.sh` grew a new `ingest` stage (Quick=normalize; Standard/Full=normalize,fidelity-gate) added via the minimal case-row insertion idiom established in P05's `roadmap` stage. `commands/ingest.md` grew from 90 to 142 lines: the Workflow expanded from 6 to 10 steps (detect-shape → normalize → resolve-policy → fidelity-gate → chunker → rebuild, with the original P06 steps preserved verbatim in renumbered slots), Usage grew `--review`/`--no-review`/`--force`-after-BLOCK flags, Reference Files grew 8 new bullets (all 6 P06 bullets preserved), and a new "Pre-chunker pipeline errors (P07)" Error Handling subsection documents seven new failure modes.

T04 delivered the closeout: `tests/fixtures/arbitrary-prd.md` (foreign-shaped PRD), `tests/fixtures/normalized-stub.md` (spec-kit-shaped stub), full sandbox E2E using `NORMALIZER_STUB=1` + `CONVERSUS_STUB=1` for determinism, PASS/BLOCK/`--force`-after-BLOCK coverage, Bash 3.2 compat scan across 20 files (4 production + 16 P07 verify), `docs/ingesting-arbitrary-specs.md` (222-line user guide covering flags, BLOCK resolution, stub modes, graceful degradation, gate-preset extension), dogfood evidence set under `.orchestrator/milestones/M011/phases/P07/evidence/` (`detect-shape.txt` → `shape=foreign`, `normalize-transcript.txt`, `gate-result.md` with `verdict: "PASS"`, `chunker-transcript.txt` with 20 CREATED lines, `timing.txt` → `elapsed_seconds=3`, `normalized-spec.md`), and a preserve-references regression extending P06's pattern to cover the new P07 ingest.md bullets.
