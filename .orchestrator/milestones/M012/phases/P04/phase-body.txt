P04 closed M012's dogfood loop: a deployable wiki with a finalized orientation home page, a consolidated operator guide, a chained deploy wrapper, a first-deploy record contract, and an 11-gate phase verification suite.

## What was built

**T01 — Home page + SSOT guard.** `wiki/docs/index.md` became a 65-line orientation layer (four required section headings: What this site is / How to navigate / Where to comment / Audience scope) with the `## Deploy & preview` pointer and five stub-route links. `scripts/verify/m012-p04-index-ssot.sh` forbids any ≥40-char home-page paragraph from appearing verbatim in canonical `.orchestrator/**.md` artifacts. The gate's `T*-PLAN.md` / `T*-PAYLOAD.md` exclusion was forced by a real scan issue — task plans legitimately quote the expected home-page prose as the specification.

**T02 — README first-deploy checklist + deploy-wrapper section.** `wiki/README.md` extended from 276 → 420 lines via EOF append, preserving prior P02/P03 sections byte-identically. New `## First-deploy checklist` (8 steps: Pages source, Discussions, Wiki Comments category, four `GISCUS_*` env vars, `wiki-deploy.sh` invocation, `DEPLOY-RECORD.md` recording, deployed-URL smoke test) and `## Running the deploy wrapper` (pipeline/flags/output-lines/exit-codes/failure-triage reference).

**T03 — Chained deploy wrapper.** `scripts/wiki/wiki-deploy.sh` (161 lines, mode 0755, Bash 3.2 compliant) runs four gates in strict order (`wiki-giscus-config-check.sh --quiet` → `mkdocs build -f wiki/mkdocs.yml` → `wiki-link-check.sh --site wiki/site` → `wiki-giscus-smoke.sh --site wiki/site`) before `mkdocs gh-deploy --force`. Flags: `--dry-run / --help / --root DIR / --skip-smoke`. Output lines: `GATE: <name> PASS|FAIL`, `BUILD: ok|fail|skip`, `DEPLOY: pushing to gh-pages`, one `DRY-RUN:` / `OK:` / `FAIL:` terminator. Exit codes 0 all-PASS, 1 any-FAIL, 2 usage. Aborts loudly on any non-zero gate.

**T04 — DEPLOY-RECORD.md (fixture-sentinel path).** Auto-mode dispatch has no `gh-pages` push rights, no `GISCUS_*` env vars, no live network. The plan's dual-path provision shipped the `pending` sentinel record (`deployed_url: pending`, `commit_sha: pending`, `deployer: pending`, all four `gate_*_result: skip`) for the human operator to fill in at M012 close-out.

**T05 — 11 gates + phase-suite orchestrator.** `scripts/verify/m012-p04-*.sh` × 11 + `m012-p04-phase-suite.sh`. Gates cover: home-page finalized, home-page SSOT (T01's), README first-deploy, wrapper contract, wrapper --help, wrapper --dry-run, wrapper loud-fail, DEPLOY-RECORD, bash-3.2 compat, wiki-removable, and summary-walkthrough (SKIP-as-PASS when `P04-SUMMARY.md` is absent). Allow-lists of `m012-p01-wiki-self-contained.sh` and `m012-p03-wiki-removable.sh` extended so P04 artifacts land cleanly without tripping prior phases' scans. Regression: P01 suite 2/9 PASS (pre-existing nav/placeholder failures inherited, not P04 regressions); P02 suite 9/9 PASS; P03 suite 8/8 PASS; P04 suite 11/11 PASS.

## Key decisions

- **AD-3 SSOT with a spec-quote exclusion** — `T*-PLAN.md` / `T*-PAYLOAD.md` are specifications that quote the expected artifact content as the task spec. Excluding them from the SSOT scan was necessary to avoid self-referential false positives.
- **EOF-append pattern for multi-author operator guides** — `wiki/README.md` uses `## Heading` boundaries (no marker comments like P01/P03 mkdocs.yml blocks). New sections append at EOF; prior bytes preserved.
- **Chained-gate deploy wrapper pattern** — N sequential single-script-file gate invocations, first-non-zero aborts, per-gate `GATE: <name> PASS|FAIL` output for downstream record-keepers. No YAML driver, no plugin system (Constitution XIV).
- **MEM004 carve-out for wrapper + gate internals** — `scripts/wiki/` and `scripts/diagnostics/` internals may use pipes and `$(...)`; the agent-facing invocations stay single-script-file shape (AD-19).
- **Graceful-absent-tool and graceful-absent-artifact patterns** — mkdocs missing → `BUILD: skip` under `--dry-run` only (exit 0), exit 1 on live path. `wiki/site` missing → link-check and giscus-smoke both `SKIP`. Dev laptops usable without polluting the deploy path.
- **Pending-sentinel deploy record** — auto-mode dispatch cannot push to `gh-pages`; the record ships with `pending` slots and `gate_*_result: skip` for the human operator to fill in.
- **Accept-on-absent phase-close gate** — `m012-p04-summary-walkthrough.sh` emits `SKIP:` as PASS when `P04-SUMMARY.md` is absent, because the summary is a phase-close artifact not a task-execution artifact.
