## What Was Built

P01 ships the Tier 1 emitter for observability and efficiency metrics: a zero-token-growth JSONL record stream covering payload composition, dispatch usage, and unit close across task / phase / milestone granularities, with Goodhart-paired cost + quality blocks on every close record. No Tier 2/3 surface — no `orchestrator:cost` command, no rollup script, no efficiency footer, no anomaly checks, no UI.

Six tasks landed in strict linear order:

- **T01** (`773fea7`) — `scripts/lib/pricing.sh` (sourceable bash 3.2 lib: `pricing_file_path`, `pricing_last_updated`, `pricing_stale_days`, `pricing_is_stale`, `pricing_resolve_alias`, `pricing_lookup_rates`, `pricing_estimate_cost_usd`, `pricing_warning_reason`, `chars_to_tokens_quartile`; honors `ORCH_PRICING_FILE`; never aborts caller — returns empty + module-scoped `_PRICING_WARNING_REASON` on missing / stale / no-rate). `scripts/verify/m019-schema.sh` (pure-bash JSONL validator: enforces `record_type` / `source` / `granularity` enums, `unit_close` cost + quality pairing, pre-M019 additivity). Pitfall captured for downstream tasks: BSD awk treats `in` as a keyword, so awk vars starting with `in_` silently zero; use `ival` / `oval`.

- **T02** (`9e4c0e5`) — `scripts/dispatch/build-context.sh` emits one `payload_breakdown` JSONL record per invocation to `.orchestrator/milestones/<Mxxx>/execution-log.jsonl` (fields: record_type, unitId, milestone, phase, task, payload_chars, payload_tokens_estimate via `chars_to_tokens_quartile`, section_tokens per context-recipe section, token_estimate_method: "char-quartile", model, source: "estimate", timestamp). - **T03** (`eab79f3`) — `scripts/dispatch/dispatch-interface.sh` emits one `dispatch_usage` JSONL record per invocation after BACKEND is resolved, on both happy and error paths (backend_crashed exit 5; backend_malformed schema / type exit 6). Resolved T01's subshell pitfall — estimator stdout captured via tmp-file so the module-scoped `_PRICING_WARNING_REASON` survives for the warning read.

- **T04** (`aa9d383`) — `scripts/knowledge/write-summary.sh` emits one `unit_close` JSONL record per `task | phase | milestone` invocation, carrying BOTH a cost block (summed from the unit's `payload_breakdown` + `dispatch_usage` records; null propagates up the aggregation chain — Tier 1 degradation signal preserved across rollup) AND a quality block (verification_pass_rate, deviation_count, retry_count derived per AD-3 from existing `attempt` / `outcome` / `verification_result` fields — no new event surface). `m019-schema.sh` source enum extended to `estimate | runtime | aggregate`. ## Key Decisions

- **Zero-token instrumentation (SC-6).** Emitters write to JSONL log files, never into the payload. `PAYLOAD_CAPTURE` tempfile + `cat` pattern in `build-context.sh` is the load-bearing trick: stdout is produced by `cat`, the emitter runs after and contributes zero bytes. `zero-token-growth` gate normalizes `hit_count: N` lines before `cmp` (knowledge shared-state drift is orthogonal to payload-bytes).
- **Goodhart pairing (C2 / SC-3).** Every `unit_close` carries both cost and quality; schema validator rejects records missing either. Pairing happens at emission time, not at rollup, so Tier 2 cannot accidentally optimize cost in isolation.
- **Schema additivity for Tier 2/3 forward compat (SC-4).** `source: estimate | runtime | aggregate` and `granularity: task | phase | milestone` enums reserved at Tier 1. `record_type` is a discriminator. Tier 3 backend-actuals adapters land additively — no Tier 1 record-writer needs modification.
- **Pre-M019 consumer additivity (C3 / SC-10).** New fields are additive only; `duration_s`, `outcome`, `verification_result`, `attempt`, `unitId` keep current semantics + positions. `scripts/state/derive-phase.sh` unchanged. Pre-M019 records still validate.
- **Never-abort degradation (C4).** Pricing lib returns empty on missing / stale / no-rate, sets module-scoped warning; emitter records `estimated_cost_usd: null` + `pricing_warning`, exits 0. Dispatch continues.
- **Test seam (ORCH_M019_EMIT).** Env-var early-return on all three emitters so SC-6 byte-identity can be measured in-place; production defaults on.
- **SC-12 epoch ordering (D009).** `2026-04-18T02:21:28Z` (P00-SUMMARY `completed_at`) is the first instant any emitter record may appear in a post-M011 milestone's log. Enforced by lexical ISO-8601 compare. Live scan on M015 / M016 / M019 / M021 is clean.
