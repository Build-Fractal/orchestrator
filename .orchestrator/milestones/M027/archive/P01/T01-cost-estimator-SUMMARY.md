Created scripts/engine/cost-estimate.sh (466 lines, executable, sourceable). Implements the M027 P01 predictive cost estimator as a sourceable bash 3.2 library + CLI. The library function cost_estimate_per_tier emits a 3-row Quick/Standard/Full Goodhart-paired table with COST_USD, INPUT_TOK, OUTPUT_TOK, QUALITY, RECOMMENDED columns and the verbatim D027 trailer; --format json emits a single-line object whose top level carries recommended plus tiers, with each tier carrying cost_usd, input_tokens, output_tokens, quality, pricing_warning. cost_usd is JSON null on pricing degradation. char-quartile token model (M019 AD-1) is inlined as bash arithmetic in the per-tier path (no per-row chars_to_tokens_quartile fork). Per-tier overhead constants 800/2400/6800 chars and output budgets 1500/4000/12000 tokens are tuned-by-eye against M019 baseline; revisitable when Tier 3 runtime-actuals lands. Model resolution: ORCH_COST_ESTIMATE_MODEL env override, then pricing_resolve_alias default, then hard-coded claude-opus-4-7 fallback (matches CLAUDE.md Opus 4.7 declaration). Recommendation hook cost_estimate_recommend forks intensity-recommend.sh, parses the intensity= line, lowercases via tr; INTENSITY_RECOMMEND_FAST_PATH=1 short-circuits the fork when callers pre-set _CE_RECOMMENDED. Pricing degradation never aborts (CON-5/FR-24) - missing or stale rates yield unavailable cost cells, the QUALITY column still renders (Goodhart pairing held), an override hint line is emitted, and the recommendation flows. Read-only (CON-1/FR-12) - only stdout/stderr writes.
