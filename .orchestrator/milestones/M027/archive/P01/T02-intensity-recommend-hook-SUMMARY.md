Modified scripts/engine/intensity-recommend.sh (now 367 lines, from 137 pre-T02) to add the M027/P01 cost-annotation hook per D026. Two new flags: --format text|json (default text; unknown values exit 2) and --no-cost-annotation (boolean; suppresses the trailing cost block in text mode). The 8 byte-stable key=value lines (intensity, confidence, reasoning, scope, risk_level, complexity, risk_signals, cap_score) are preserved unchanged in text mode for any given input — verified by diffing pre-T02 captured output against post-T02 head -8 (BYTE-STABLE-OK, CON-3 carry-forward). After the existing analyze + profile + decision-matrix block, the script now sources scripts/engine/cost-estimate.sh, sets _CE_RECOMMENDED to the lowercased local intensity (preventing T01's library from re-forking this script — no-recursion invariant), exports INTENSITY_RECOMMEND_FAST_PATH=1, and captures cost_estimate_per_tier <desc> --format json into cost_json. On empty output a hardcoded fallback JSON object is installed and a stderr WARN line is emitted. Empty $DESCRIPTION (operator fed pre-computed analyze/profile flags only) emits an additional stderr WARN: cost-estimate description=empty line per task plan step 4. Per-tier values are extracted from cost_json via two bash 3.2 safe helpers — _cj_field uses a sed regex to pull a single field from one tier (returns raw value: numeric, null, or quoted-string-with-quotes), and _cj_unquote strips surrounding double-quotes for string fields. Text mode emits the 9 numeric cost-annotation lines (3 tiers x cost_usd plus input_tokens plus output_tokens), 3 quality-pairing lines (cost_quick_quality, cost_standard_quality, cost_full_quality — CON-4/FR-20 Goodhart pairing satisfied at the predictive intensity-recommend surface), and a final cost_pricing_warning= line that picks the first non-empty per-tier warning (rolled-up form). When pricing is unavailable (ORCH_PRICING_FILE=/tmp/nonexistent.yml) the cost_*_usd fields render empty and cost_pricing_warning=pricing-missing. JSON mode emits a single-line object containing the 8 existing fields plus a top-level cost_estimates object keyed by quick/standard/full where each tier carries cost_usd, input_tokens, output_tokens, pricing_warning per D026 — cost_usd renders as JSON null on pricing degradation while pricing_warning carries the reason. JSON-string fields (intensity, confidence, reasoning, etc) are run through _json_escape which uses sed to escape backslashes and double-quotes and tr to flatten newlines. cap_score renders as bare numeric (unquoted).
