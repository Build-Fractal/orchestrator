## Lessons carried forward to M027 milestone summary + future work

- **T04-subsumes-prechecks pattern** is now fully canonical (M027/P00, P01, P02, P03 — four occurrences). Plan-phase agents should always generate per-task scoped prechecks for tasks shipping structural changes; T04 deletes them once canonical phase-level verifiers ship.
- **Document-shaped phase-task pattern** is the canonical way to integrate helpers into runtime-rendered command documents (commands/<cmd>.md). Attach point + verbatim-tail baseline fixture + canonical-section-order assertion = byte-identity contract enforceable in CI.
- **Markdown-aware bash32-compat scanner** — when `.md` files are in the scan-set, extract only fenced bash/sh code blocks before applying forbidden-construct regex; prose discussion of bash syntax does not false-positive.
- **Verifier-author-vs-helper-author boundary**: when a phase-plan key-link asserts a transitive reference and adding it the literal way would invalidate a baseline fixture, the cleanest fix is a one-sentence transitive-reference note inside an existing section (rather than a new bullet that breaks the fixture).
