## Patterns established

- **Strict-aggregation driver pattern (T01)**: every emitted line traces verbatim to an upstream sub-flow output file. NO LLM, NO conversus, NO model routing. Constitution XV codification. Negative-grep tripwire on the driver's non-comment code path.
- **Floor-not-ceiling discipline (T01)**: prescribed-section set as a closed floor; operator additions preserved via pre-write scan + verbatim re-append.
- **Branch-dependent section variant pattern (T01)**: detect upstream output file presence, then render Source-Docs XOR Entry Points.
- **Set-e-safe rc-capture pattern (T02)**: `cmd || rc=$?` rather than `cmd; rc=$?` for additive extensions into set-e scripts where caller needs to inspect non-zero return.
- **Stub-mode-vs-real-mode-vs-genuine-failure three-way branch (T02/T03)**: stub_env=true => synthetic emit + synthetic rc; real_target_present => bash invoke; neither => printf-error rc=1. MIT-001 two-mode test contract template.
- **Paired-launch passthrough mirror pattern (T03)**: `github_init_passthrough` is structurally a copy of `wiki_init_passthrough` with FR-15->FR-16 + WIKI->GH + M033_FR15_STUB->M033_GHINIT_STUB substitutions.
- **Post-gate-ordering via code position (T03)**: no explicit if-wiki-then-github conditional needed -- T02 gate exits on failure and falls through on success, T03 gate inserted immediately below.
- **Explicit-enumeration discovery model (T04, MIT-002)**: closed enum roster comment block in `run-acceptance-battery.sh` doubles as traceability documentation for M033-VALIDATED gate; min-line-floor padding satisfied.
- **Awk-block-injection pattern for cross-platform Notes section insert (T04)**: replaces `sed -i.bak` with literal `\n` which is unportable across BSD and GNU sed.
- **Config.yml seed pattern for acceptance tests against staged dirs (T04)**: prevents `init-project.sh` side effects on the staged fixture.
- **PROJECT_DIR threading as load-bearing emitter prefix pattern (T04)**: mirrors `migrate_routing` pattern and the `customblock-draft.sh` pattern.
- **Milestone-close gate procedural-authorship pattern (T05)**: executor runs three gates (AD-7), then conditionally authors `VALIDATED` marker with gate verdict language reflecting the actual path taken.
- **Direct printf append for one-time milestone-grain events not in shipped closed enum (T05)**: bypasses emitter library without additive enum extension; payload explicitly endorses this path.
- **US-8 AS-5 signed-attestation fallback discipline (T05)**: cold-start risk acknowledgment + recruiting outreach deadline + maintainer signature.
