Per-channel exclusion-filter resolved per the plan's §Description decision: pre-compute the per-channel exclusion union in the caller, not in `_byte-equivalence-hash.sh`. Rationale (plan-cited): leaves the helper's contract unchanged (P02's existing consumers don't need to learn a new env var) and the caller already has the channel context. The caller-side change replaces the inline awk pipeline at block 1 with two helper invocations — one with `CHANNEL=npm`, one with `CHANNEL=homebrew` — emitting `EXCLUSION_LIST_NPM` (6 paths) and `EXCLUSION_LIST_HOMEBREW` (5 paths). The npm-channel arm sets `EXCLUSION_LIST="$EXCLUSION_LIST_NPM"` immediately before invoking the hash helper; the homebrew arm sets `EXCLUSION_LIST="$EXCLUSION_LIST_HOMEBREW"`.

The new homebrew arm (block 3) re-uses the npm-pack tarball per D007 — a separate brew-tarball would introduce an independent build path whose hash drift versus npm would mask the very divergence CON-5 exists to catch. The arm extracts the tarball into `$BREW_FIXTURE`, flattens `package/*` into `$BREW_FIXTURE/Cellar/orchestrator/<version>/` via `cp -R "$BREW_FIXTURE/package/." "$CELLAR/"` + `rm -rf "$BREW_FIXTURE/package"` (works across exotic FS where `mv` fails), then hashes the staged tree with the homebrew-channel exclusion list applied. The fixture Cellar layout mirrors T01's `def install Dir["package/*"]` flatten — any divergence between formula's def install and T03's fixture would mean the byte-equivalence test misrepresents what `brew install` would stage.

Block 5 (cross-channel equality assertion) fires only when both arms emit hashes; when either is absent (e.g. tarball not produced, npm absent), the assertion SKIPs rather than spuriously failing. On match: `PASS: cross-channel byte-equivalence — NPM_HASH = HOMEBREW_HASH` (em-dash U+2014). On mismatch: both hashes are emitted plus a remediation pointer to `references/installation.md § Channel-specific metadata files`. The curl-pipe-bash SKIP stub now lives inside block 5 (folded from the old block 4 per plan §Steps 4c).

D009 was not authored. The plan does not call for it.
