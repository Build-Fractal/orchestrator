# M036 — Reference-corpus ingest (M036a scope)

M036 delivered the full pre-launch reference-corpus pipeline — a tiered extraction stack (Tier 0 manifest + binary preservation, Tier 1 deterministic shell adapters for PDF/DOCX/XLSX/Markdown, Tier 2 LLM-driven structured Markdown via M030 routing under conversus fidelity gate), the ingest layer that promotes extraction outputs to chunks under a four-category taxonomy, the graph-schema extension (three new edge types + a fourth scope-tag namespace), idempotent re-extract + re-ingest with supersede chain mechanism, and the dispatch context-builder injection with token-budget governor. Eight phases (P00–P07). Closed 2026-05-02 with cross-phase regression spread across P02 selective + P03/P04/P05/P06/P07 full pass-through; a P03 live-LLM smoke test against a representative fixture landed 2026-05-07 (commit `c03efcc4`) and is captured in the deferred-validation audit trail at `M036-ACCEPTANCE-EVIDENCE.md`. ## Patterns established

- **Tiered extraction architecture** (Tier 0 manifest + binary preservation; Tier 1 deterministic shell adapters; Tier 2 LLM-driven via M030 routing under conversus fidelity gate) — the canonical orchestrator-owned extraction shape for any future content-type-typed ingest pipeline.
- **CON-3 closure preservation via two-seam test mode** — `EXTRACT_TIER_2_DISPATCH=stub:pass|stub:block|live` for LLM dispatch and `CONVERSUS_STUB=1` + `CONVERSUS_STUB_VERDICT=PASS|BLOCK` for the gate; CI exercises full pipeline without live LLM calls. Live-mode default-closed via `ORCHESTRATOR_TIER2_LIVE=1`.
- **FR-18 "no silent failure" gating** — BLOCK verdicts retain only a `block.md` audit log; PASS promotes `.structured.md` to chunk store; ingest layer defends in depth via BLOCKED stdout + absence-of-`.structured.md` assertion.
- **Pure-lib MEM004 helper shape** — `classify-reference.sh` has only function definitions (no top-level execution); sourceable from drivers and verifiers; carried forward as the M036-canonical helper-library shape.
- **Two-tier classifier composition** — FR-2 required-field check authored locally + delegation to the existing P00 T03 validator for FR-1 taxonomy + tier-enum check; preserves SSOT for taxonomy lookup, avoids duplicating the category list.
- **`_negative/<reason>/` subdirectory naming convention** — co-locates rejection-path fixtures with positive corpus; top-level taxonomy walker silently skips `_negative/`; per-rejection-mode verifiers address them directly.
- **Workspace-staging-into-cms-rule pattern** — negative fixtures whose fixture must be picked up by a top-level taxonomy walker get staged into `mktemp -d /cms-rule/` by the verifier before driving the driver; M036-standard for any negative-path verifier.
- **Cross-phase selective-gate-list regression pattern** — when a phase's deferred-error verifier is replaced by the next phase's full-implementation verifier, the cross-phase regression check explicitly enumerates the unchanged gates and skips the one whose semantics flipped (M036/P03/T03 + M036/P04/T03 precedent). Canonical for future cross-phase regression verifiers.
- **Idempotency-via-tree-snapshot** — `find -type f` + per-file sha256 + sort + `diff -q` snapshots gives byte-identical-tree assertion that is the hard CON-4 contract regardless of whether per-line SKIPPED reporting fires.
- **Additive case-block amendment pattern for rebuild-index.sh** — `MEM*|SPEC-*)` widened to `MEM*|SPEC-*|REF-*)` with new `*.text|*.structured)` exclusion branch added above; superstring grep-positive-check is sufficient since old pattern is fully consumed by new pattern.
- **Bundle-manifest discipline** — relocated `validate-chunk-frontmatter.sh` from `tools/verify/lib/` to `scripts/knowledge/lib/` (commit `259a6dc7`) because `tools/` is not in the install bundle manifest. Lesson recorded in `.orchestrator/KNOWLEDGE.md`: any runtime-required helper must live under a directory staged by the install bundle.
