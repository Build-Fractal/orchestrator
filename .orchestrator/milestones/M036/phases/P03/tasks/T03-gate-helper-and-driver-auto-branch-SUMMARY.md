T03 lands the synchronous Tier 2 gate-and-promote path of the M036 P03 reference-corpus extraction pipeline: a pure gate helper (extract-tier-2-gate.sh) wrapping the conversus adapter, an inverted sentinel return from the P02 tier-0 summary lib so tier=2+auto no longer hard-errors, and the driver-side dispatch+gate+promote/retain wiring with PASS/BLOCK retention semantics. Six new verifiers gate the artifact contracts; three observational-red at T03-close pending T04 canned fixtures.

**What was built**:

- `scripts/knowledge/lib/extract-tier-2-gate.sh` — ~70-line pure helper lib (Bash 3.2 / POSIX-sh per CON-2; sourced from the driver alongside extract-tier-2-llm.sh). Two pure functions:
  - `extract_tier_2_invoke_gate <artifact> <output>` — shells out to `scripts/dispatch/adapters/tool/conversus.sh gate tier-2-fidelity $artifact $output` with the `CONVERSUS_GATE_SKIP_TODO_CHECK=1` bypass (extracted structured Markdown may legitimately contain TODO-shaped strings inherited from the source). Translates the conversus exit-code contract: 0 PASS / 2 BLOCK / other -> 1 (adapter error). Refuses to invoke on missing artifact or non-executable adapter with stderr diagnostic + return 1.
  - `extract_tier_2_promote_or_retain <verdict> <tmp> <chunk_dir> <cite_id> <category> <gate_out> <log_dir>` — on PASS (verdict=0): mv tmp to `<chunk_dir>/REF-<category>-<cite_id>.structured.md` + cp gate_out to `<log_dir>/<cite_id>.pass.md`. On BLOCK (verdict=2): cp gate_out to `<log_dir>/<cite_id>.block.md` + rm tmp (do NOT promote — FR-18 invariant). Unknown verdict -> stderr diagnostic + return 1.

- Modified `scripts/knowledge/lib/extract-tier-0-summary.sh` — auto-branch flips: tier=2 prints sentinel `__TIER_2_AUTO__` on stdout exit 0 (was: hard-error citing P03 not implemented). tier!=2 + auto continues to deferral-error so the M036/P02 deferral semantics for non-tier-2 chunks are preserved (validated by the m036-p02-tier-2-deferred-error.sh test on a tier!=2 manifest — but the existing P02 verifier was authored against tier:2 fixtures, so its semantics intentionally flip at P03; selective-gate-list regression pattern handles this).

- Modified `scripts/knowledge/extract-reference.sh` — adds two source lines after the existing P02 sources (extract-tier-2-llm.sh from T02, extract-tier-2-gate.sh from T03). Adds a Tier 2 dispatch block in the per-doc loop triggered when `summary_text == __TIER_2_AUTO__`: mktemps the structured-md and gate-result paths, calls `extract_tier_2_dispatch` capturing stub stderr metrics into a metrics_file, calls `extract_tier_2_invoke_gate` under `set +e/rc=$?/set -e` to capture the conversus exit-2-on-BLOCK without aborting, calls `extract_tier_2_promote_or_retain` with the captured rc, parses NAME=VALUE metrics back into MODEL/TOKENS_IN/TOKENS_OUT/COST_USD/QUALITY_SCORE with safe defaults, calls `extract_tier_2_emit_unit_close`, and cleans up temp files. Adds `tier_2_verdict` frontmatter field to the chunk emit when set; emits `BLOCKED: <cite_id> reason=fidelity-gate` stdout on BLOCK and `EXTRACTED: ... verdict=PASS|BLOCK` on Tier 2 success — operator|stub paths unchanged (no `tier_2_verdict` set, original EXTRACTED stdout preserved).
