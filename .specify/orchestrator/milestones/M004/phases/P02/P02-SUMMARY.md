P02 delivered 5 Bash 3.2 sourced shared libraries (total 647 lines) providing the foundation for the M004 engine layer. scripts/lib/errors.sh establishes the closed 6-kind error taxonomy (CONFIG/STATE/DISPATCH/VERIFY/BUDGET/IO) and emit_result, the single-line RESULT: emitter every engine-managed script must call. scripts/lib/events.sh provides emit_event and a 19-entry canonical event registry (SESSION_*/TASK_*/PHASE_*/DISPATCH_*/GUARD_*/HOOK_*/CHECKPOINT_*), threading $ORCH_RUN_ID and $ORCH_STARTED_AT into every EVENT: line for correlation. scripts/lib/run-context.sh implements Principle IX reproducibility via init_run_context — deterministic when seeded (cksum-based hash → stable run_id + ISO timestamp anchored at 2026-01-01 + hash-mod-year offset), random-nonce otherwise — plus orch_now/orch_is_forced/orch_is_dry_run helpers. scripts/lib/guards.sh composes the first three and provides the 4 FR-224 safety rails (guard_payload_sanity, guard_budget, guard_output_sanity, guard_phase_complete) with a _guard_block helper routing blocks through GUARD_BLOCKED or GUARD_WARNING+forced=1 under ORCH_FORCE. scripts/lib/hooks.sh delivers run_hooks at the 4 US5 AS2 lifecycle points (PRE_DISPATCH/POST_DISPATCH/POST_VERIFY/PRE_ADVANCE), enforcing Principle XII hook isolation via chmod 444 frozen state snapshots passed in $ORCH_HOOK_SNAPSHOT, a portable Bash 3.2 background-watchdog timeout (30s default via ORCH_HOOK_TIMEOUT_SEC, no dependency on timeout(1)), and mtime+mode tampering detection that emits HOOK_VIOLATION and blocks unconditionally even under ORCH_FORCE.
