Phase P07 delivered the onboarding capstone. Created scripts/lifecycle/detect-project.sh — scans project for 10 language markers (Node/Python/Rust/Go/Ruby/Java/PHP/dotnet/Swift/Elixir), 9 framework markers (Next/Nuxt/Vite/Remix/Svelte/Angular/Django/Rails/Astro), 6 CI systems, 9 tools, plus project_type/has_git/has_tests. Pure read-only, file-presence driven, no network or manifest parsing. Created templates/project-instruction.md with {{placeholder}} syntax per MEM013 and <!-- BEGIN CUSTOM -->/<!-- END CUSTOM --> markers on own lines for user-editable sections. Created commands/init.md MEM012-compliant command doc with description frontmatter, Workflow (4 numbered phases), Flags table, Exit Codes, Referenced Scripts/Templates. Created scripts/lifecycle/init-project.sh — top-level orchestrator:init entry point with detect→probe→generate→verify pipeline that delegates to detect-runtime.sh (P05), detect-capabilities.sh (P01), detect-project.sh (T01), resolve-root.sh (P04), and runtime-specific installer from packaging/install/ (P06). Generates config.yml + project-instruction.md at runtime-specific locations (claude-code→CLAUDE.md, codex→AGENTS.md, cursor→.cursor/rules/orchestrator.md). Exit codes: 0 success, 1 bad args, 2 detection failure, 3 install failure, 4 existing config (without --force). Created scripts/lifecycle/reinit-handler.sh — update/reset/abort modes. update mode (default) preserves BEGIN CUSTOM block in instruction file and preserves user top-level fields in config.yml via awk surgery; reset delegates to init --force; abort exits 0 with no changes. Non-interactive default emits REINIT: lines and exits 4 requesting explicit --mode. Static hermetic-only gate prevents future verifier regressions that would leak writes to real HOME. Full onboarding e2e completes in ~1 second wall-clock vs 120s budget — validates SC-005 (<5min first task) with 2 orders of magnitude margin. Patterns established: (1) project introspection via marker-file presence (zero parsing, fast, offline-safe), (2) user-edit preservation via comment-delimited blocks enabling safe regeneration, (3) top-level pipeline delegation — init orchestrates detect/probe/generate/install through existing P01/P04/P05/P06 scripts rather than reimplementing, (4) reinit-with-preservation via awk field-level surgery, (5) wall-clock budget enforcement + hermetic-only static gate.
