# Code of Conduct

This project adopts the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1, as its Code of Conduct. Everyone who participates — contributors,
maintainers, issue reporters, and discussion participants — is expected to
abide by it. The full text lives at the link above.

In short: be respectful, welcoming, and constructive. Treat others the way you
would want to be treated in a professional open-source community.

## Scope

This Code of Conduct applies within all project spaces — the repository,
issues, pull requests, and discussions — and when an individual is officially
representing the project in public spaces.
