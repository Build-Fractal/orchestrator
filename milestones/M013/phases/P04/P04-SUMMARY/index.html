    Key patterns established (12)¶

    • additive-helper-append-preserves-byte-identity — new public helpers appended before github-common.sh self-check block; prior function bodies untouched.
    • walker-shape-symmetry — sync reuses init's projectable-phase walker with phases-first-milestone-last ordering swap for manifest-SSOT alignment.
    • idiomatic-lock-variable-gate — assertion accepts LOCK_MGR=<path>/lock-manager.sh + bash $LOCK_MGR create as valid invocation shape without requiring literal one-line match.
    • direct-cmd-subst-rc-propagation — assign $() then read $? on next line; || true in cmd-subst tail silently zeros $?.
    • rate-limit-preflight-budget-check — projected GraphQL volume > remaining budget → short-circuit rc=3 before first mutation.
    • per-call-stderr-mktemp-classify-rm — capture stderr to mktemp, classify_gh_rc rc + file, rm -f on all paths; releases lock before exit 3/4.
    • fixture-copy-before-live-gate — gates that exercise live mode copy fixture orchestrator-state to tmp (cp -R fx/. tmp/) rather than running against repo fixture; github-sync.sh reassigns ORCHESTRATOR_ROOT to $PROJECT_ROOT/.orchestrator and would pollute the repo tree otherwise.
    • shared-helper-for-T05-reuse — emit_conversus_gate_record authored in github-common.sh under T03 ownership so T05's standalone gate sources and reuses the same shape.
    • FR-12-v1-negative-grep-guard — byte-identity preservation on sibling-runtime files via negative greps for post_verify/FR-12 markers across codex/cursor installers+adapters; cheaper and more readable than pinned-sha baselines; self-repairs if codex/cursor later gain legitimate P04 content under a different marker.
    • external-watchdog-plus-adapter-internal-timeout — kill -TERM at TIMEOUT then kill -KILL at TIMEOUT+1s belt-and-suspenders over adapter's own timeout (Constitution XII).
    • verdict-rc-parity — rc=0 PASS, rc=2 BLOCK, rc=1 ERROR passed verbatim through gate; BLOCK distinguishable from error; upstream loop treats BLOCK as per-row error via if-guarded increment.
    • pinned-SHA-with-awk-range-capture-before-edit — multi-phase additive doc editing workflow: capture awk-range shasum pre-edit, edit, embed literal digest in gate post-edit; extends gate-evolution-on-legitimate-advancement (P04/T06 relaxes P03/T04 gate analogously to P03/T04 relaxing P02/T05 gate).
