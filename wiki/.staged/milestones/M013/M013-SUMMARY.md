## What Was Built

M013 ships the GitHub-native integration: orchestrator state projects to GitHub Issues + Project v2 + Milestones with FR-4 byte-identity markers, a sync cycle wires lifecycle hooks for closure, UAT bug ingestion closes the loop back to spec chunks, and an opt-in conversus PR gate enforces adversarial review at merge points. Four phases (P01 → P02 → P03 → P04), 25 task summaries, ~30 verify gates across four phase-suite orchestrators. The integration is **opt-in** via an operator-owned sidecar (gitignored at `.orchestrator/integrations/github.json`); orchestrator state on disk remains authoritative — GitHub is a projection, not a peer (Constitution XIV + [M007](../../milestones/M007/index.md) + D007).

The milestone's binding pre-discuss commitments (D014, applied via conversus red-blue pressure test of `specs/023-github-native-integration/spec.md`) all landed: **FR-12 Claude-Code-only v1** (Codex/Cursor parity demand-driven post-launch); **Minimal Slice subsection** (P01 ships an end-to-end demo before any sync surface); **FR-9 narrowed to additive-only emit** with chunk-IDs pinned to existing `SPEC-*` frontmatter (Knowledge-Layer Boundary preserves [M020](../../milestones/M020/index.md) chunk-ID authority); **FR-16** rate-limit + auth-expiry exit-code contracts; **FR-17** cost emission via [M019](../../milestones/M019/index.md) Tier 1 shape; **FR-18** `status --verify-cache` read-only divergence probe.

## Key decisions

- **D014** — Knowledge-Layer Boundary: M020 retains chunk-ID authority. M013 cross-links the M020 schema; never redefines or extends it. Zero writes to `knowledge/spec/**` from any P01–P04 task. FR-9 `## Spec Chunks` emit is additive-only (`emit_spec_chunks_section` appends after `write_full_index`; pre-existing pipe-table body remains byte-identical).
- **D015** — P02/P03 scope split applied as load-bearing markers. P02 ships three `_deferred to P03_` cells in the Partial Mapping Table and three `### TODO P03:` reference doc stubs; P03 fills the cells in place and relabels the stubs `### TODO P04:`; P04 fills those.
- **FR-12 Claude-Code-only v1** — Binding via X+XII (Single-Hands-On Runtime + Constitution-Bounded Exception). P04's post-verify hook ships only Claude Code wiring; Codex/Cursor adapters and installers are byte-identity-preserved via negative-grep guard (cheaper than pinned-sha and self-repairs if those runtimes legitimately gain P04 content under a different marker). v2 (multi-runtime parity) is demand-driven post-launch.
- **Projection-not-peer** grounded on Constitution XIV (No Speculative Complexity) + M007 single-user/project + D007 hard-migrate. Sidecar is operator-owned, gitignored at `.orchestrator/integrations/github.json`; in-repo template at `templates/github-integration-sidecar.json`.
- **FR-11 reversibility** — All writes have absent/pending exit paths: `status --verify-cache` short-circuits to pending-operator-complete on absent OR pending sidecar; `perform_upsert` releases the lock before rate-limit/auth-expiry exits; post-verify hook fail-as-warning never blocks the dispatch loop.
- **AD-19 single-script-file Check shape** — preserved across all 30+ verify gates. Comment-discipline synonyms (assoc-arrays, array-from-stdin builtins, case-conversion expansion, combined-redirect shorthand) keep bash32 scanners self-clean across P02–P04.
- **`write-summary.sh --field-file=`** — added to honor AD-19 shape safety for long milestone/phase bodies (no multiline quoted CLI args).

## Key patterns established (cross-cutting M013)

- **`additive-helper-append-preserves-byte-identity`** — every github-common.sh extension (P02 ships 12 helpers; P03 appends `gh_marker_search_remote` + `manifest_footer` 4th arg; P04 appends `http_probe`, `sidecar_update_item_cache`, `emit_tier1_record`, `classify_gh_rc`, `emit_conversus_gate_record`) lands at end-of-helpers before the self-check block, with prior function bodies untouched.
- **`gate-evolution-on-legitimate-advancement`** — when a later phase legitimately fills earlier-phase scaffolding, the earlier-phase assertion evolves to accept both pre/post shapes rather than fracturing the suite (P02→P03 mapping table; P03→P04 reference extensions). Byte-identity hashes on content NOT being advanced stay pinned as load-bearing invariants.
- **`pinned-SHA-with-awk-range-capture-before-edit`** — multi-phase additive doc editing: capture awk-range shasum pre-edit, edit, embed literal digest in gate post-edit. Three pinned ranges in `references/github-integration.md` (P01 Overview..Sidecar Schema; P02 init Workflow..Dry-Run Manifest Format; P03 Re-init Adoption Contract..Sync Workflow).
- **`FR-12-v1-negative-grep-guard`** — sibling-runtime byte-identity preserved via negative greps for `post_verify` / FR-12 markers across codex/cursor installers + adapters.
- **AWK-based JSON upsert / count / first-scalar extraction** — depth-aware brace walker for `items.<oid>` upserts, awk count + first-scalar for marker-search results. `jq` stays optional throughout M013 (MEM001).
- **`M013_GH_STUB_DIR` fixture-driven preflight + marker-search stub-selector** — env-var-driven stub paths let preflights and marker probes deterministically exercise every branch without `gh` calls. Pattern extends from P02 preflights to P03 marker-search to P04 sync rate-limit probes.
- **PATH-shimmed fake-gh** — auto-mode SC-7 zero-`gh`-write invariant enforcement: tests log every `gh` invocation and assert the log is empty.
- **`per-call-stderr-mktemp-classify-rm`** + **`direct-cmd-subst-rc-propagation`** — capture stderr to mktemp, `classify_gh_rc rc + file`, `rm -f` on all paths. Bug caught mid-T03: `probe_out="$(http_probe … || true)"` silently zeroed `$?` — fix: assign `$()` then read `$?` on next line.
- **`external-watchdog-plus-adapter-internal-timeout`** — Constitution XII belt-and-suspenders: `kill -TERM` at TIMEOUT then `kill -KILL` at TIMEOUT+1s wraps the conversus adapter's own timeout.
- **`verdict-rc-parity`** — rc=0 PASS, rc=2 BLOCK, rc=1 ERROR passed verbatim through gates so BLOCK is distinguishable from error; upstream loop treats BLOCK as per-row error via if-guarded increment.
- **Pending-sentinel bootstrap with clobber-refusal exit 2** — inherits the M012/P04 DEPLOY-RECORD convention; extends to sidecar config and verify-cache divergence probe.
- **`fixture-copy-before-live-gate`** — gates that exercise live mode `cp -R fx/. tmp/` before invoking `github-sync.sh`, because the script reassigns `ORCHESTRATOR_ROOT` to `$PROJECT_ROOT/.orchestrator` and would pollute the repo fixture tree otherwise.
- **`stdout-record + stderr-summary split`** — fixture diffs stay byte-identical while operator still sees per-run summary.
- **Comment-discipline synonyms in bash32 scanners** — `assoc-arrays`, `array-from-stdin builtins`, `case-conversion expansion`, `combined-redirect shorthand` keep self-scanning gates clean of their own anti-pattern matches.
