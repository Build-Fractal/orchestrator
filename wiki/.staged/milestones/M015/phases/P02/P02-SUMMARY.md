P02 State Tree Migration is complete. Orchestrator state lives at `.orchestrator/` and the constitution lives at `.orchestrator/memory/constitution.md`; `.specify/orchestrator/` and `.specify/memory/` are gone from the repo. `scripts/state/resolve-root.sh` is reduced from a 5-rule resolver (with a `.specify/orchestrator/` bridge at Rule 4) to a 4-rule standalone resolver — bridge removed, secondary `.specify/orchestrator/config.yml` probe removed, default and explicit-override semantics preserved. The resolver now emits `source=existing:.orchestrator` from the repo root with no env overrides.

T05's sweep touched ~43 runtime files (lifecycle, knowledge, dispatch, diagnostics, engine, verify, commands, templates, `.gitignore`, `packaging/bundle/README.md`, `ANTIPATTERNS.md`) with literal path replacements from `.specify/orchestrator` → `.orchestrator` and `.specify/memory/constitution` → `.orchestrator/memory/constitution`.
