T01 ships the anomaly-detection helper that backs the M027/P03 doctor anomaly-detection pass. The helper (scripts/diagnostics/check-anomalies.sh,~205 lines) is sourceable as a library (function check_anomalies_render) AND runnable as a CLI; it re-uses the P00 rollup engine to compute milestone-to-date per-task aggregates,computes a moving-median baseline per scope,and prints an anomaly block (<=12 lines) prefixed "Anomaly Detection (Tier 1 baseline)".

scripts/state/read-config.sh VALID_KEYS was extended with four anomaly knobs (anomaly_cost_multiplier,anomaly_retry_threshold,anomaly_pass_rate_threshold,anomaly_check_enabled) in a single edit per the multi-key co-location pattern.

The T01-scoped precheck (scripts/verify/m027-p03-t01-shape-precheck.sh) asserts 13 invariants covering structural,reference,and behavioral must-haves; it ran green against the post-T01 codebase. T04 will subsume this precheck with the canonical phase-level m027-p03-anomaly-shape.sh.

Two implementation lessons surfaced during smoke-testing against the live [M013](../../../../milestones/M013/index.md) / [M021](../../../../milestones/M021/index.md) logs and were folded into the helper before commit: (1) read-config.sh returns the literal string null for unset-but-registered keys,which awks mixed-type comparison treats as a string and would silently flag every row via lexicographic 1.00 < null = true; the fix treats both empty AND null as use-built-in-default before passing to awk,plus a BEGIN numeric coercion makes the per-row END loop type-stable. (2) The metrics-rollup.sh (N missing) annotation in column 5 shifts subsequent columns by +2; the awk pass detects this per-row and selects PASS_RATE/RETRIES from columns 10/12 instead of 8/10,plus marks cost_unavail so the emitter substitutes cost=(unavailable; fallback=duration) per CON-5.
