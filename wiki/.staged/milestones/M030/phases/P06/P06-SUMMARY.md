P06 closes the FR-18 anomaly-driven regression detection surface for M030: `scripts/diagnostics/check-anomalies.sh` gains a per-class rolling-window verifier-fail-rate check that emits a `model_routing_regression` anomaly record (text + JSONL) when a class crosses the configured threshold (default pass_rate 0.50, min_class_sample 10; both overridable via `.orchestrator/config.yml model_routing_regression.{pass_rate_threshold,min_class_sample}`). The text line surfaces through `orchestrator:doctor` via the existing [M027](../../../../milestones/M027/index.md) "Anomaly Detection" advisory invocation — `run-doctor.sh` already calls `check-anomalies.sh` and renders its stdout, so no doctor-side amendment was required.
