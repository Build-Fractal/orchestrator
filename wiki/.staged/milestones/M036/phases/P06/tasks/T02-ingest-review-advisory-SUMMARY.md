T02 wires the cross-citer REVIEW: advisory pass into scripts/knowledge/ingest-reference.sh and authors the supporting pure-lib helper at scripts/knowledge/lib/ingest-review-advisory.sh. After the existing per-chunk classify/idempotency loop completes, the driver now invokes review_emit_for_superseded_chunks() to walk the reference root for chunks with superseded_by: frontmatter and emit one REVIEW: <citer-id> reason=cites-superseded target=<prior-id> tip=<new-id> line per citer (FR-11). The opt-in --detect-removals + --prior-manifest flag pair triggers review_emit_for_removed_chunks() which enumerates chunk-ids present in the prior manifest but absent from the current corpus and emits REMOVED: <chunk-id> + REVIEW: <citer-id> reason=cites-removed target=<chunk-id> lines. The pass is advisory only (Principle XV / FR-11) — ingest never exits non-zero on a REVIEW; the helper short-circuits to a no-op if the typed-edge traverser is missing.

What was built:

- scripts/knowledge/lib/ingest-review-advisory.sh (pure-lib MEM004 helper; no top-level execution; sourceable). Two public functions: review_emit_for_superseded_chunks(reference-root) walks the four taxonomy categories (cms-rule|training-material|glossary|regulatory-doc) for REF-*.md chunks with a superseded_by: frontmatter field, then per-chunk invokes the typed-edge reverse traverser (scripts/knowledge/traverse-graph.sh --start <chunk_id> --edge-types cites --reverse --depth 1) and emits one REVIEW: line per citer; review_emit_for_removed_chunks(reference-root, prior-manifest-file) reads the prior-manifest line-by-line, checks each chunk-id for absence under any taxonomy category, and emits REMOVED: + REVIEW: lines for each missing chunk's citers. Two internal helpers: _review_fm_field reads single-line frontmatter values with leading-whitespace + surrounding-quotes strip; _review_find_citers wraps the traverser invocation with awk-based citer-id extraction, swallows traverser-absent / index-empty conditions silently (advisory contract).

- Pure-lib MEM004 carried into the ingest-review surface — lib/ingest-review-advisory.sh exposes function definitions only (review_emit_for_superseded_chunks + review_emit_for_removed_chunks + two internal helpers _review_fm_field + _review_find_citers); no top-level execution; sourceable from the driver and any future test harness. - Post-loop advisory-pass pattern — the REVIEW: emission is intentionally OUTSIDE the per-chunk classify/idempotency loop so the SUMMARY: counters (created/skipped/rejected/blocked) remain loop-counters and are not perturbed by REVIEW: emission. The advisory pass runs as a contiguous block after the per-chunk loop closes and before the SUMMARY: line. This is the canonical M036 ingest-driver shape for any future cross-chunk advisory passes (e.g. P09 operator-facing scale UX may add additional REVIEW: families).

- Defensive traverser invocation pattern — _review_find_citers tolerates traverse-graph.sh being missing or returning zero citers silently (return 0 with no stdout). The advisory contract is "emit when possible, never block ingest"; if the typed-edge traverser is broken or the index is empty, the REVIEW: emission becomes a no-op rather than a crash. Reusable pattern for any future advisory pass that consumes graph data.

- Controllable-input behavioral verifier pattern — the --detect-removals path is testable in isolation because the prior-manifest is a simple text file the verifier authors directly under mktemp -d, no graph-state staging required. The supersede path is harder to test behaviorally in a workspace because the typed-edge traverser queries the project's global KNOWLEDGE-INDEX rather than a workspace-local one; the workspace verifier therefore only asserts ordering invariants + helper-shape token presence, deferring full integration to the T04 SC-6 harness which controls graph state via fixture staging into knowledge/spec/ under the workspace root. Pattern-rule: when behavioral testing requires global index state, split the verifier into a workspace-isolated leg (assert helper-invocation + ordering) plus a fixture-staged leg in the acceptance harness (assert end-to-end emission shape).

- Opt-in flag default-and-arm pattern — DETECT_REMOVALS=0 + PRIOR_MANIFEST="" defaults declared above the case block; case block adds two new arms BEFORE the *) catch-all; post-loop pass conditional on BOTH flag-set AND prior-manifest-non-empty (defensive: --detect-removals without --prior-manifest is a no-op rather than a crash). The negative leg of the removed-detection verifier confirms the opt-in semantics — without the flag, no REMOVED: line is emitted.

- Heredoc-based citer-loop pattern — the helper consumes _review_find_citers stdout via a here-doc construct (`while IFS= read -r citer; do ... done <<EOF / $(_review_find_citers ...) / EOF`) rather than process-substitution to remain Bash 3.2 / POSIX-sh compatible per CON-2.
