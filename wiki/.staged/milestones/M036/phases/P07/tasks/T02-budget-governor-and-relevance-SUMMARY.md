1. scripts/dispatch/lib/reference-budget.sh (new, ~55 lines): pure-lib MEM004 exposing reference_apply_budget(list_file, budget_tokens). Pass 1 reads the input chunk_id|token_count|chunk_path records and emits chunks while running total stays at-or-below budget (FR-3 + FR-7 chunk-level granularity — chunks are dropped whole, never mid-chunk truncated). Pass 2 implements the FR-8 at-least-one-chunk invariant: when pass 1 emitted zero (every chunk individually exceeded budget), re-read head -n 1 of the input file, print WARNING: smallest chunk exceeds budget; emitting one chunk to stderr, then emit the first chunk record to stdout. Choosing the first chunk in input order is correct because reference_rank has already ordered the input.

2. scripts/dispatch/lib/reference-relevance.sh (new, ~75 lines): pure-lib MEM004 exposing reference_rank(cand_file, task_topic_tags_csv, task_applies_to_field_csv) + helper _ref_overlap_count(chunk_csv, task_csv).
